# fn64 launch keel

one-line pitch: the small authority graph for taking fn64 to a truthful public developer preview.

This keel records current outcomes, blockers, checks, and landing order. The
technical derivations and clean-room evidence remain in `docs/`; keel nodes
link to them rather than restating or replacing them.

Commands:
- `keel lint ./keel`
- `keel tasks ./keel`
- `keel graph ./keel`
- `keel doc ./keel`
